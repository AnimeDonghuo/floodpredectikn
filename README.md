# Jio Shield 🛡️
### Real-Time Flood Advance Warning & Risk Intelligence System

Jio Shield is a production-grade, highly performant disaster mitigation command center. It monitors precipitation, forecast projections, historical deviations, and hydrological water heights to output a highly descriptive and structured **0-100 Flood Risk Index**.

---

## 🛠️ Key Architectural Highlights
1. **Rule-Based Risk Matrix Engine**: Multi-variable normalized algorithm weighting live precipitation indexes, historical monsoon baselines, topographic drainage vulnerabilities, and river rate-of-rise factors.
2. **Robust Multi-Layer Database Failback**: Uses a MongoDB layer with a completely self-healing offline in-memory fallback.
3. **No Paid APIs Required**: Powered entirely by the Open-Meteo Weather APIs. No registration keys needed.
4. **Interactive GIS Map**: Fully responsive Leaflet implementation styled using premium dark maps from CartoDB.
5. **Interactive Hackathon Presentation Suite**: Includes a dynamic scenario dashboard simulator, changing risk models and updating maps/charts/warnings on the fly.
